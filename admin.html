One-time setup: connect your inquiry database

This admin panel reads from a free Supabase database. Three steps, about 5 minutes:

  1. Create a free project at supabase.com (name it jag-crm).
  2. Open SQL Editor and run the script in supabase-setup.sql (it's in this website's repo). Then add your login under Authentication → Users → Add user.
  3. Copy Project URL and the anon public key from Project Settings → API into the top of jag-capture.js in the repo.

Reload this page after — the sign-in screen appears and every form on the site starts logging here automatically.

Lola's weekly home emails

Every week Lola emails Houston-area leads new HAR listings in their budget, from their assigned agent (replies go to that agent). It started with a pilot of the 100 newest leads; when fewer than 5% unsubscribe or bounce, 300 more are added each day until everyone is in. If 5% or more do, it pauses itself. Leads can say what they want, pause or unsubscribe from a link in every email; their agent gets a notification when they say what they want.
